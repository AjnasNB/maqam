# Recorded YC demo

- [Silent 47-second MP4](maqam-yc-control-plane-demo.mp4)
- [Final proof poster](maqam-yc-control-plane-poster.png)

Both files were captured from the live dashboard. The recorder starts the
local server, opens visible Chrome on Windows, runs the real combined workflow,
pauses for the exact approval, rejects console errors, captures the 1920 by
1080 desktop, and renders an H.264 MP4 without an audio stream.

The raw browser recording, extracted review frames, contact sheet, and recorder
logs are local verification material and are intentionally ignored.
