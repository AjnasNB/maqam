Product definition

What is Maqam?

Maqam is an open-source TypeScript governance boundary for operations deliberately routed through registered tools.

It evaluates policy before a handler runs. When approval is required, Maqam binds that decision to the exact run, tool name, and canonical input hash. The approved call is consumed once by default, changed input and replay are rejected, and the result can be linked to trace and evidence records.

Where Maqam sits

Before dispatch
Policy evaluates the registered tool, effects, origins, run, tenant ceilings, and requested input before the handler executes.
At approval
The approval request identifies the exact run, tool, and canonical input rather than a loose natural-language description.
At execution
The gateway consumes a valid approval before dispatch and rejects altered scope, a different run or tool, and replay.
After execution
Receipts, traces, evidence records, and claims can retain the reviewed input identity, decision, outcome, and source links.

What it can govern

  • Registered functions and SDK calls

    Wrap a host-owned function or adapter and declare its minimum effects and origins.

  • Command-line workers and coding agents

    Run fixed executables without shell evaluation under explicit event, byte, token, environment, directory, and duration limits.

  • Browser action contracts

    Govern structural observe, preview, apply, and submit plans through an injected browser driver that remains a separate host boundary.

  • Research sources and bounded crawling

    Route configured sources through a governed caller and normalize bounded public-source evidence.

  • Workflow side effects

    Apply the same policy, approval, execution, trace, and evidence path to selected workflow tasks.

What Maqam does not do

Maqam does not intercept direct operating-system, network, provider, browser, SDK, or unregistered calls. It does not replace identity, authentication, durable approval storage, operating-system isolation, a browser engine, or service-specific authorization. A host must deliberately route an operation through the registered gateway and secure the surrounding infrastructure.
