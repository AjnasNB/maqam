Release scope

Clearer distribution, the same execution boundary.

  • Public package presentation

    The npm README and release record describe the current Maqam, Cockroach Crawler, Qarinah, and ProductLoop OS responsibilities without silently combining their runtimes.

  • Runtime behavior retained

    Policy, approval, source, browser, credential, dispatch, and replay boundaries are unchanged from 0.3.2.

  • Exact release identities

    The npm artifact, registry metadata, GitHub tag, and release remain independently inspectable. Historical measurements stay attached to the versions that produced them.
