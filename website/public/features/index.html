Maqam 0.3.3 capability map

Maqam features

A visible map of the source-backed product surfaces. The complete detailed inventory remains versioned beside the implementation.

Status boundaryThese groups describe public 0.3.3 code, types, tests, or explicit host contracts. Optional adapters still require their named executable, credential, driver, network reader, or host authority.
  • Installation and runtime surfaces

    ESM package, TypeScript declarations, Node.js 22, 24, and 26, CLI, server export, local console, and packed-consumer checks.

  • Policy engine

    Tool, effect, origin, run, goal, tenant, token, and call ceilings with allow, deny, and approval-required decisions.

  • Tool gateway and execution receipts

    Explicit registration, pre-dispatch policy, canonical input, effect and origin enforcement, approval consumption, traces, and receipts.

  • Exact one-use approvals

    Request, approve, reject, serialize, restore, consume, reject changed scope, and reject replay.

  • Evidence and claims

    Normalized immutable records, content hashes, run and task isolation, scoped evidence access, and explicit claim links.

  • Workflow runtime

    Sequential tasks, retries, timeouts, cancellation, goal ceilings, pause and resume, scoped evidence, traces, and results.

  • Skill registry

    Validated manifests, deterministic selection, capability and trigger filters, duplicate rejection, and immutable descriptions.

  • Agent and object adapters

    Governed wrappers for functions, object agents, SDK calls, HTTP, MCP-style clients, and custom host transports.

  • Command-line worker adapters

    Fixed commands, no shell evaluation, JSON Lines events, bounded output, allowed environment, rooted working directories, aborts, and process summaries.

  • Codex and Claude Code adapters

    Provider-specific CLI adapters and normalized events under explicit configuration and bounded error records.

  • Governed browser adapter contract

    Structural observe, preview, apply, and submit phases with opaque refs, plan hashes, expected origins, re-observation, and trusted-driver attestations.

  • Research document model

    Normalized immutable research documents with adapter, channel, URI, content, metadata, dates, authors, and citations.

  • Governed source routing

    Validated adapters, deterministic ordering, backend preference, authentication modes, governed and explicitly ungoverned calls, timeouts, and failure classification.

  • Public research adapters

    Host crawler, feeds, optional public media metadata, and optional hosted search routes under explicit configuration.

  • Built-in bounded crawler

    HTTP traversal with public-network defaults, DNS and redirect checks, robots handling, origins, sitemaps, feeds, requests, bytes, depth, retries, and deadlines.

  • Release gate

    Artifact identity, evidence requirements, reviewer authorization records, readiness reporting, and explicit publication checks.

  • Local server and console

    Loopback-first operator interface and server export with deployment-owned authentication and remote-boundary requirements.

  • Security and hostile-input handling

    Detached immutable inputs, closed contracts, redaction, bounded values, prototype and accessor rejection, and fail-closed governance errors.

  • Verification and benchmark surfaces

    Tests, clean-consumer TypeScript checks, package checks, MGES conformance and local-call measurement with explicit limitations.
