Install Maqam 0.3.3

Verify the public artifact, run the isolated exact-approval proof, then add the pinned package only where a registered tool needs the governance boundary.

1. Verify the release

Registry tags can move. Confirm the version, package integrity, registry source commit, provenance, and matching source release before installation.

npm view maqam@0.3.3 version dist.integrity gitHead
npm view maqam@0.3.3 --json

2. Run the isolated proof

The proof needs no model key, hosted account, browser, database, or external side effect. It creates a temporary workspace, rejects changed input, executes the exact approved write once, rejects replay, verifies evidence, and removes the workspace.

npx -y maqam@0.3.3 demo approval
npx -y maqam@0.3.3 demo approval --json

3. Install in a project

npm install maqam@0.3.3

Maqam is an ESM package with TypeScript declarations. The root export contains the application-side governance APIs; maqam/server exposes the separate server surface.

4. Register one governed tool

Before connecting a real side effect, define the tool's minimum effects and origins, the exact input a reviewer must see, which effects require approval, trusted reviewer identity and persistence, handler idempotency, recovery behavior, credentials, and external authorization.

Authority boundaryInstallation does not intercept direct SDK, shell, browser, MCP, network, provider, or operating-system calls. Only operations deliberately routed through a registered Maqam gateway receive its policy, approval, execution, trace, and receipt path.
